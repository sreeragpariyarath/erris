# Security Policy

## Supported versions

Erris has not published its first package version. No released version is
currently supported.

This policy will be updated before the first public release with an explicit
support window for maintained versions.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request.

Report security concerns privately by emailing
[psreerag69@gmail.com](mailto:psreerag69@gmail.com). Include:

- The affected component or package
- The observed and expected behavior
- Reproduction steps or a minimal proof of concept
- Potential impact
- Any suggested mitigation

Do not include real credentials, personal data, or third-party secrets.

We aim to acknowledge a report within 48 hours. Acknowledgement is not a
guarantee that the report is accepted as a vulnerability.

## Disclosure process

When a report is confirmed, maintainers will:

1. Restrict sensitive discussion to the smallest necessary group.
2. Identify affected versions and consumers.
3. Prepare and verify a fix from a known-safe commit.
4. Rotate any potentially exposed credentials.
5. Publish a security advisory and patched release when ready.
6. Credit the reporter unless anonymity is requested.
